# Kleinkram

Organizer gegen Aufschieben: Kalender mit Bereichen, Routinen mit Serien, Punkte und Titel, Rechnungs-Scanner mit GiroCode, Steuer-Jahresordner und Spar-Topf. Alle Daten bleiben auf dem Gerät.

- **APK:** unter *Releases* → `Kleinkram.apk` (neueste Version immer unter `releases/latest/download/Kleinkram.apk`)
- **Web-App:** über GitHub Pages, installierbar über das Browser-Menü („Zum Startbildschirm hinzufügen“)

Jeder Push auf `main` baut beides automatisch neu (`.github/workflows/app-bauen.yml`).
